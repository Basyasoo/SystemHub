# SystemHub Manager 🚀

**SystemHub** — это современная и стильная системная утилита для Windows, вдохновленная лучшими элементами Центра управления macOS. Она объединяет в себе мониторинг ресурсов вашего компьютера, управление медиафайлами, очистку системы и другие полезные инструменты в едином, красивом и плавном интерфейсе.

---

## 🌟 Ключевые возможности

### 📊 Мониторинг системы и ресурсов
* **Панель характеристик:** Просматривайте детальную информацию о вашем процессоре (CPU), видеокарте (GPU), материнской плате, оперативной памяти (RAM) и дисках в реальном времени.
* **Производительность:** Следите за текущей нагрузкой на систему с помощью наглядных индикаторов.
* **Состояние VPN:** Быстро проверяйте, активно ли ваше VPN-подключение прямо сейчас.

### 🧹 Очистка диска (Cleaner)
* **Безопасная очистка:** Сканируйте и безопасно удаляйте ненужный кэш приложений, временные файлы системы, кэш предвыборки (Prefetch) и лог-файлы.
* **Очистка Корзины:** Очищайте Корзину на всех дисках в один клик для освобождения места.

### 🎵 Медиа-центр (Media Hub)
* **Единый пульт:** Управляйте воспроизведением музыки и видео во всех активных приложениях и браузерах (Spotify, Яндекс Музыка, YouTube и др.).
* **Контроль громкости:** Регулируйте громкость отдельных аудио-сессий и быстро переключайте треки.

### ☁️ Погода (Weather Forecast)
* **Точный прогноз:** Подробный прогноз погоды на текущий день и 7-дневная перспектива благодаря интеграции с `api.met.no` (со встроенными обходами блокировок и прокси для работы в любых сетевых условиях).
* **Автолокация:** Автоматическое определение вашего города по GPS/IP или удобный ручной поиск.

### ⚙️ Менеджер автозапуска (Startup Control)
* **Управление запуском:** Легко настраивайте программы, которые запускаются вместе с Windows, чтобы сократить время загрузки системы.
* **Автозапуск SystemHub:** Включайте и отключайте запуск самой утилиты в фоне.

### 📦 Быстрый установщик программ (App Installer)
* **Установка в один клик:** Быстро и безопасно устанавливайте популярный софт на чистую систему в бесшумном режиме.

## 🛠 Технологический стек

* **Язык разработки:** C#
* **Платформа:** .NET 8.0 (Windows)
* **Интерфейс:** Avalonia UI (с поддержкой темных и светлых тем, сглаживания и плавной анимации)
* **Архитектурный паттерн:** MVVM (CommunityToolkit.Mvvm)

## 💾 Установка и запуск

Поскольку исходный код этого проекта закрыт и является частной интеллектуальной собственностью, в репозитории опубликованы только готовые сборки.

1. Перейдите в раздел **[Releases](https://github.com/Basyasoo/SystemHub/releases)** на панели справа.
2. Скачайте последнюю версию установщика `SystemHubSetup.exe`.
3. Запустите скачанный файл и следуйте простым инструкциям установщика.

*Программа автоматически создаст ярлыки и предложит настроить автозапуск при первом запуске.*
